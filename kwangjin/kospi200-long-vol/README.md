# KOSPI200 변동성 계속 매수 백테스트

KOSPI200 월물 옵션으로 **스트래들 · 스트랭글 · 스트랩 · 스트립 매수**와 **콜 버터플라이 매도**를 신호 없이 항상
들고 있다가(모두 변동성 매수 방향) 만기 전에 다음 월물로 롤하는 전략 12개를 일별 데이터로 백테스트하는 리서치 저장소입니다.
날개(K/F 0.90/1.10, 25델타)와 델타헤지 여부를 조합했습니다.

> **한 줄 결론** — 이 표본(2025-10 ~ 2026-10, 204일)은 KOSPI200이 +73.6% 오르고 실현변동성이 내재변동성을
> 웃돈 해여서, 스트래들·스트랭글·스트랩 매수가 모두 플러스였습니다(+3.9% ~ +25.3%). 델타헤지는 수익률 부호는 그대로 두고
> MDD를 30~40% 수준으로 줄였습니다. 콜 버터플라이 매도는 날개에서 이익이 막혀 −5.9% ~ +2.2%로 거의 본전이었습니다.
> 롤이 13번뿐이라 통계적으로 유의한 결과는 없고(|NW t| ≤ 1.2),
> 장기적으로는 변동성 매도가 버는 것이 보통이므로 이 한 해의 결과로 일반화할 수 없습니다.

## 실행

```bash
pip install -r requirements.txt
# data/ 폴더에 KRX 원자료 CSV 3개를 넣는다 (data/README.md 참고)
python run_all.py                  # 결과표 출력 + 전략별 그래프 12장
python run_all.py --no-plot        # 결과표만
python run_all.py --save figures   # 그래프를 figures/ 에 PNG로도 저장
pytest -q                          # 단위 테스트 (원자료 불필요)
```

**Spyder**에서는 `run_all.py`를 열고 F5를 누르면 됩니다. 그래프는 Plots 창에 전략별로 한 장씩 나옵니다.

저장소·데이터 폴더는 자동으로 찾습니다 (저장소 `data/` → 작업 폴더 → 바탕화면/다운로드/문서와 그 하위 폴더 2단계까지, OneDrive·한글 폴더명 포함). 실행하면 결과표 맨 위에 사용한 데이터 폴더가 표시됩니다.
못 찾으면 `python run_all.py --data-dir 데이터폴더경로`. 처음 한 번은 일별 스마일을 만드느라 1~2분 걸리고, 이후에는 `.cache`를 써서 10초 안쪽입니다.

## 출력

1. **결과표 1개** — 전략 12개: 누적수익률, 비용 제외 누적수익률, Sharpe, MDD, 롤당 평균수익률, 승률, 롤 횟수, 대체평가 비율, Newey-West t
2. **그래프 12장** — 전략마다 한 장, 누적수익률 선 하나

### 전략 12개 (모두 변동성 매수 방향)

| 구조 | 날개 | 델타헤지 없음 | 델타헤지 |
|---|---|---|---|
| 스트래들 (풋 + 콜, K=F) | — | ✓ | ✓ |
| 스트랭글 (풋 날개 + 콜 날개) | 0.90 / 1.10 | ✓ | ✓ |
| 스트랭글 | 25Δ | ✓ | ✓ |
| 스트랩 (풋 1 + 콜 2, K=F) | — | ✓ | |
| 스트립 (풋 2 + 콜 1, K=F) | — | ✓ | |
| 콜 버터플라이 **매도** (콜 K1 매도 / 콜 F 2개 매수 / 콜 K3 매도) | 0.90 / 1.10 | ✓ | ✓ |
| 콜 버터플라이 매도 | 25Δ | ✓ | ✓ |

* **25Δ 날개**는 진입일 스마일의 IV로 계산한 |델타| = 0.25인 풋·콜 행사가입니다 (이 표본에서 평균 K/F ≈ 0.93 / 1.09).
* **나비 매도 = 변동성 매수.** 롱 버터플라이(날개 매수, 몸통 매도)는 가격이 제자리에 있어야 버는 변동성 매도이고, 그 반대인 나비 매도는 크게 움직여야 버는 변동성 매수입니다. 다만 날개를 팔았기 때문에 날개 밖에서는 이익이 막힙니다("상한이 있는 스트래들 매수"). 25Δ처럼 행사가 간격이 다르면 날개 수량을 `2(K3−K2)/(K3−K1)`, `2(K2−K1)/(K3−K1)`로 맞춰 양쪽 꼬리의 만기 손익을 0으로 만듭니다.
* **스트랩·스트립은 델타헤지 버전을 넣지 않았습니다.** 베가를 맞추면 스트랩 = 스트래들 + 선물 매수 1/3, 스트립 = 스트래들 + 선물 매도 1/3이라, 델타헤지하면 둘 다 스트래들과 똑같아집니다.

## 방법 요약

**IV 스마일.** 날짜·만기별로 거래량 ≥10, 미결제약정 ≥10, IV 3~150%, 잔존 5~180일, K/F 0.85~1.15 필터를 통과한 OTM 옵션의 IV를 거래량 가중해 스마일을 만들고, 행사가 방향으로 선형 보간합니다(진입 시 외삽 없음). F는 같은 만기 선물 종가입니다.

**롤 규칙.** 신호·손절·보유일 제한 없이 항상 변동성 매수 포지션을 듭니다. 잔존 5일 미만이 된 날 종가에 팔고, 다음 날 잔존 10일 이상인 가장 가까운 월물을 삽니다 (보통 잔존 약 30일에 사서 약 4일에 팔아 월 1회 롤).

**크기.** 구조 전체 베가 = 진입일 ATM 스트래들 1개의 베가. 구조끼리 같은 변동성 노출로 비교하기 위함입니다.
콜 버터플라이만 몸통 = ATM 콜 2개(≈ 스트래들 1개 베가)로 둡니다. 베가를 맞추면 몸통과 날개가 상쇄돼 수량이 폭주하기 때문입니다.

**회계.** 손익 = (옵션 평가액 − 진입가) + 누적 헤지손익. 옵션 비용은 진입·청산 각각 레그당 0.5 IV-pt (매수는 비싸게, 매도는 싸게).
델타헤지는 매일 종가에 선물로 재헤지하고, 진입 헤지·재헤지·헤지 해제 때 거래한 선물 1단위당 0.05pt(1틱)의 비용을 뺍니다. 수익률은 롤별 진입 선물가 기준 %, 가산 누적.

**MDD.** 자본 1(진입 선물가 명목 1단위)에서 시작해 누적손익을 단순 합산한 잔고를 기준으로, 직전 최고 잔고 대비 최대 하락률(%)입니다.

**보유 중 평가.** 급변으로 행사가가 그날 스마일 범위 밖으로 나가면 날개 IV를 평평하게 외삽하고, 만기 스마일이 통째로 없으면 직전 IV를 유지해 **그날 손익을 반영**합니다(건너뛰거나 전날로 청산하지 않음). 결과표의 `대체평가 %`가 이렇게 평가한 보유일의 비율입니다.

- **왜 플러스인가.** 델타헤지한 옵션 매수는 보유기간 동안의 실현분산이 매수 시 내재분산보다 크면 법니다. 이 해는 변동성이 계속 커져 그 조건이 성립했습니다. 신호를 써서 사고팔던 버전(`kospi200-option-structures` 저장소)은 과거 20일 실현변동성을 기준으로 판단해 "터진 뒤에 사고 조용할 때 파는" 타이밍이 되어 대부분 마이너스였는데, 같은 구조라도 그냥 계속 사면 이 해의 변동성을 그대로 가져갑니다.
- **델타헤지 vs 무헤지.** 무헤지는 롤 시점까지의 순이동(방향 포함)에, 델타헤지는 매일 움직임의 크기(실현변동성 vs IV)에 겁니다. 그래서 무헤지 스트래들은 6월에 +44%까지 갔다가 하반기에 반납했고(MDD −35.8%), 델타헤지는 같은 기간을 MDD −10.4%로 지나갔습니다.
- **스트랩·스트립의 차이는 시장 방향입니다.** 스트랩(선물 매수 1/3 효과)은 +73% 상승장에서 이기고, 스트립(선물 매도 1/3 효과)은 졌습니다. 변동성 엣지가 아닙니다.
- **나비 매도는 거의 본전입니다.** 이 해의 수익은 날개를 넘어가는 큰 움직임에서 많이 나왔는데, 나비 매도는 팔아 둔 날개가 그 부분을 되돌려 줍니다. 그래서 MDD는 스트래들보다 훨씬 작지만(−4.3 ~ −14.8%) 비용 전 수익도 −3.1% ~ +5.0%에 그치고, 레그가 3개라 비용(약 2.8%p)이 그중 상당 부분을 가져갑니다.
- **비용 영향이 작습니다.** 월 1회 롤이라 옵션 비용은 버터플라이 외 1.5~1.7%p, 델타헤지 선물 비용은 약 0.2%p입니다(선물 비용을 5틱으로 올려도 델타헤지 스트래들 +10.1% → +9.2%).

## 한계와 주의

* **표본:** 204일, 큰 상승장 하나의 단일 사이클, 롤 13회. 결과는 이 해의 변동성 환경을 보여줄 뿐이고, 장기적으로는 변동성 위험 프리미엄 때문에 매도가 버는 것이 보통입니다.
* **롤 시점 민감도:** 무헤지 결과는 언제 롤하느냐에 크게 좌우됩니다. 같은 스트래들 매수도 보유일을 5·10·20일로 바꿔 평균하면 +20.2%였습니다.
* **날개 평가:** 0.90/1.10 날개는 보유일의 64%, 25Δ는 52%를 외삽 IV로 평가했습니다. 실제 날개 IV는 보통 더 높아 수치가 다소 틀릴 수 있습니다.
* **일별 데이터:** 체결가는 종가, 델타헤지는 하루 한 번 종가에만 합니다. 옵션 비용(0.5 IV-pt)과 선물 비용(1틱)은 가정치이며 `config.py`에서 바꿀 수 있습니다.
* **단순화:** 무위험금리 연 2.5% 고정, 증거금·포지션 한도 미모델링. 이 저장소는 학습·리서치 목적이며 투자 권유가 아닙니다.
