# KOSPI200 옵션 기본 구조 백테스트 (5년 판)

KOSPI200 월물 옵션으로 **스트래들 · 스트랭글 · 스트랩 · 스트립 · 콜 버터플라이**를 만들고,
날개(K/F 0.90/1.10, 25델타)와 델타헤지 여부를 조합한 전략 12개를 일별 데이터로 백테스트하는 리서치 저장소입니다.
진입 신호는 VRP(근월 ATM IV − 20일 실현변동성)의 z-score입니다.

[kospi200-option-structures](../kospi200-option-structures)(1년, 2025-10 ~ 2026-10)와 전략·엔진·출력 형식이 같고,
기간만 **2021-08-26 ~ 2026-10-23 (1,208 거래일)** 로 늘렸습니다. 1년치 파일만 넣으면 원래 저장소와 똑같은 결과가 나옵니다.

> **한 줄 결론** — 5년 동안 VRP 신호로 사고판 **24개(12 전략 × 당일/익일) 모두 손실**입니다 (−6 ~ −56%, 대부분 NW t ≤ −2.4).
> 비용을 빼도 스트립 당일 하나를 빼고 전부 마이너스라, 비용 문제가 아니라 **신호 자체가 틀린 방향**을 가리켰습니다.
> 매도 쪽과 매수 쪽이 둘 다 졌습니다. 신호 없이 계속 **매수**한 기준선(스트래들 +6%, 스트랭글 0.90/1.10 +31%)이 오히려 낫습니다.

## 실행

```bash
pip install -r requirements.txt
# data/ 폴더에 기간별 KRX 원자료 CSV 15개를 넣는다 (data/README.md 참고)
python run_all.py                  # 결과표 출력 + 전략별 그래프 12장
python run_all.py --no-plot        # 결과표만
python run_all.py --save figures   # 그래프를 figures/ 에 PNG로도 저장
python run_all.py --baseline       # 신호 없이 계속 매도/매수한 기준선 표 추가 (그래프 없음)
python run_all.py --by-year        # 연도별 손익 표 추가
pytest -q                          # 단위 테스트 (원자료 불필요)
```

**Spyder**에서는 `run_all.py`를 열고 F5를 누르면 됩니다. 그래프는 Plots 창에 전략별로 한 장씩 나옵니다.

저장소·데이터 폴더는 자동으로 찾습니다 (저장소 `data/` → 작업 폴더 → 바탕화면/다운로드/문서와 그 하위 폴더 2단계까지, OneDrive·한글 폴더명 포함). 실행하면 결과표 맨 위에 사용한 데이터 폴더가 표시됩니다.
못 찾으면 `python run_all.py --data-dir 데이터폴더경로`. 처음 한 번은 5년치 일별 스마일을 만드느라 몇 분 걸리고, 이후에는 `.cache`를 써서 1분 안쪽입니다.

## 출력

1. **결과표 1개** — 전략 12개 × 체결 가정 2개(당일/익일 종가 체결): 누적수익률, Sharpe, MDD, 최악 셀 MDD, 거래당 평균수익률, 승률, 거래수, 변동성 매도 비중, 대체평가 비율, Newey-West t
2. **(선택) 연도별 손익표** — `--by-year` · **기준선 표** — `--baseline`
3. **그래프 12장** — 전략마다 한 장, 누적수익률 선 2개(당일 체결 / 익일 체결)만 그린 시계열

### 전략 12개

| 구조 | 날개 | 델타헤지 없음 | 델타헤지 |
|---|---|---|---|
| 스트래들 (풋 + 콜, K=F) | — | ✓ | ✓ |
| 스트랭글 (풋 날개 + 콜 날개) | 0.90 / 1.10 | ✓ | ✓ |
| 스트랭글 | 25Δ | ✓ | ✓ |
| 스트랩 (풋 1 + 콜 2, K=F) | — | ✓ | |
| 스트립 (풋 2 + 콜 1, K=F) | — | ✓ | |
| 콜 버터플라이 (콜 K1 / −2 × 콜 F / 콜 K3) | 0.90 / 1.10 | ✓ | ✓ |
| 콜 버터플라이 | 25Δ | ✓ | ✓ |

* **25Δ 날개**는 진입일 스마일의 IV로 계산한 |델타| = 0.25인 풋·콜 행사가입니다 (이 표본에서 평균 K/F ≈ 0.93 / 1.09).
* **스트랩·스트립은 델타헤지 버전을 넣지 않았습니다.** 같은 행사가의 콜과 풋은 감마·베가가 같아서, 매일 델타헤지하면 같은 베가의 스트래들과 손익이 똑같아집니다.
* **콜 버터플라이**는 콜 세 개로 만든 1 : −2 : 1 구조입니다. 25Δ처럼 행사가 간격이 다르면 날개 수량을 `2(K3−K2)/(K3−K1)`, `2(K2−K1)/(K3−K1)`로 맞춰 양쪽 꼬리의 만기 손익을 0으로 만듭니다. 풋-콜 패리티 때문에 같은 행사가의 아이언 버터플라이와 손익이 같습니다.
* **방향**: z ≥ E (IV가 RV 대비 비쌈)이면 변동성 매도, z ≤ −E이면 매수. 변동성 매도 = 스트래들·스트랭글·스트랩·스트립 매도, 콜 버터플라이 **매수**(몸통 매도·날개 매수).

## 방법 요약

**데이터.** `data/` 폴더의 `kospi200*_options_regular`, `*_futures_regular`, `*_spot` 파일(.csv / .csv.gz)을 기간별로 전부 읽어 날짜순으로 이어 붙입니다.

**IV 스마일.** 날짜·만기별로 거래량 ≥10, 미결제약정 ≥10, IV 3~150%, 잔존 5~180일, K/F 0.85~1.15 필터를 통과한 OTM 옵션의 IV를 거래량 가중해 스마일을 만들고, 행사가 방향으로 선형 보간합니다(진입 시 외삽 없음). F는 같은 만기 선물 종가입니다.

**신호.** VRP = 근월 ATM IV − RV20의 rolling z-score (윈도우 W∈{20,40,60}, 당일 값 제외), 진입 |z|≥E∈{1.0,1.5,2.0}.
결과표의 각 전략은 이 9개 셀의 일별 손익을 평균한 곡선입니다 (사후에 좋은 셀을 고르지 않기 위함).

**포지션.** 잔존 10일 이상인 가장 가까운 만기로 진입. 크기는 구조 전체 베가 = ATM 스트래들 1개 (콜 버터플라이만 몸통 ATM 콜 2개).
청산은 |z|<0.3, 보유 5일, 잔존 5일 미만 중 먼저 오는 것. 한 번에 한 포지션.

**회계.** 손익 = (옵션 평가액 − 진입가) + 누적 헤지손익. 옵션 비용은 진입·청산 각각 레그당 0.5 IV-pt (매수는 비싸게, 매도는 싸게).
델타헤지는 매일 종가에 선물로 재헤지하고, 진입 헤지·재헤지·헤지 해제 때 거래한 선물 1단위당 0.05pt(1틱)의 비용을 뺍니다. 수익률은 거래별 진입 선물가 기준 %, 가산 누적.

**MDD.** 자본 1(진입 선물가 명목 1단위)에서 시작해 누적손익을 단순 합산한 잔고를 기준으로, 직전 최고 잔고 대비 최대 하락률(%)입니다. 최악 셀 MDD는 9개 셀 각각의 MDD 중 가장 나쁜 값입니다.

**보유 중 평가.** 급변으로 행사가가 그날 스마일 범위 밖으로 나가면 날개 IV를 평평하게 외삽하고, 만기 스마일이 통째로 없으면 직전 IV를 유지해 **그날 손익을 반영**합니다. 결과표의 `대체평가 %`가 이렇게 평가한 보유일의 비율입니다.

**체결 가정.** 당일 = 신호가 나온 날 종가에 체결(낙관적 상한), 익일 = 다음 날 종가에 체결(보수적 하한).

**읽는 법**

- **신호가 양쪽 다 틀렸습니다.** 스트래들(당일)을 매도 거래와 매수 거래로 나누면 매도 −13.0%, 매수 −17.9%이고, 비용을 빼도 −3.8% / −9.6%입니다.
  RV20은 지난 20일의 변동성이라, "IV가 RV보다 비싸다"는 신호가 나온 뒤에 변동성이 커지고, "싸다"는 신호 뒤에는 잠잠해지는 경우가 많았습니다.
- **5년 전체로 보면 변동성 매도가 더 크게 졌습니다.** 평균 RV(23.2%)가 IV(22.1%)보다 높았고, 2024·2026년엔 RV가 IV보다 2pt 이상 높았습니다.
  신호 없이 계속 매도하면 모든 구조가 손실(스트래들 −47%, 스트랭글 0.90/1.10 −71%)입니다.
- **스트립만 덜 졌는데, 방향 때문입니다.** 스트립 매도는 풋 2개를 파는 구조라 상승장(+110%)에서 유리합니다. 매도 쪽만 보면 +7.4%(비용 제외 +16.6%)이고, 반대로 콜 2개를 파는 스트랩 매도는 −33.4%입니다. 변동성 엣지가 아니라 델타 노출입니다.
- **버터플라이는 비용이 거의 전부입니다.** 비용을 빼면 25Δ 버터플라이는 −0.4 ~ −3.3%로 거의 0인데, 비용을 넣으면 −31 ~ −34%입니다.
  베가를 ATM 스트래들에 맞추느라 수량이 커지고 레그가 4개라, 거래마다 일정하게 비용이 빠집니다. NW t −9 ~ −11은 신호의 예측력이 아니라 이 꾸준한 비용 유출입니다.
- **델타헤지**는 Sharpe를 더 나쁘게 만들거나 비슷하게 두었습니다. 방향 손익의 변동을 줄이는 대신 선물 비용이 더해지고, 손실의 원인(변동성 방향)은 그대로이기 때문입니다.

## 한계와 주의

* **다중비교:** 전략 12개 × 체결 2종 × 9셀을 비교했으므로 덜 나빠 보이는 결과(예: 스트립 당일)에는 사후 선택에 따른 낙관 편향이 있습니다.
* **날개 평가:** 0.90/1.10 날개는 보유일의 약 12%(1년 판 33%)를 외삽 IV로 평가했습니다. 실제 날개 IV는 보통 더 높으므로 숏 날개 쪽 손실을 다소 과소평가했을 수 있습니다.
* **MDD 정의:** 잔고 = 1 + 누적손익(단순 합산)이라, 손실이 100%를 넘으면 기준선 일부 셀처럼 MDD가 −100%보다 작게 나옵니다. 실제로는 증거금이 먼저 바닥납니다.
* **일별 데이터:** 호가·장중 데이터가 없어 체결가를 종가로 가정하고, 비용(0.5 IV-pt, 선물 0.05pt)도 가정치입니다. 버터플라이를 묶음 호가로 거래하면 실제 비용은 더 낮을 수 있습니다.
* **단순화:** 무위험금리 연 2.5% 고정, 증거금·포지션 한도 미모델링. 이 저장소는 학습·리서치 목적이며 투자 권유가 아닙니다.

## 이력

* **5년 판:** 데이터 폴더의 기간별 파일(옵션·선물·현물 각 5개)을 모두 읽어 이어 붙이도록 `data.py`를 바꾸고, `--by-year`(연도별 손익표)를 추가했습니다.
  엔진·전략·비용 가정은 1년 판과 같고, 1년치 파일 3개만 넣으면 결과표가 1년 판과 한 글자도 다르지 않습니다.
* 기존 `kospi200-vol-arb` 엔진은 보유 중 행사가가 스마일 밖으로 나가 보간이 안 되면 **전날 가격으로 청산**했습니다.
  이렇게 하면 급변일 손익이 통째로 빠져 숏감마 전략이 크게 부풀려집니다 (신호 없는 0.95/1.05 스트랭글 매도: 전날 청산 규칙 +18.6% → 수정 후 −27.2%).
  이 저장소의 엔진은 그날을 외삽 IV로 평가해 손익을 반영하고, `tests/test_jump_day_is_not_skipped`가 이를 검증합니다.

## 구조

```
run_all.py              실행 진입점 (결과표 출력, 전략별 그래프 표시)
src/optstruct5y/
  config.py             가정값 (비용, 신호 격자, 날개, 필터)
  data.py               KRX 원자료(기간별 여러 파일) 로드, 일별 IV 스마일, 캐시
  pricing.py            Black-76, 스마일 보간·외삽, 델타 행사가
  indicators.py         RV20, VRP, rolling z
  structures.py         스트래들·스트랭글·스트랩·스트립·콜 버터플라이 레그 생성
  engine.py             일별 백테스트 (비용, 델타헤지, 청산, 대체평가)
  metrics.py            Sharpe, MDD, Newey-West t
  experiments.py        전략 12개 목록과 실행
  report.py  plots.py   결과표, 그래프
tests/test_core.py      패리티, 25델타, 버터플라이 꼬리 손익, 매수·매도 대칭, 옵션·선물 비용 방향, 급변일 반영, 선견편향 없음, 기간별 파일 읽기
data/                   원자료 위치 (git 제외)
```

패키지 이름은 `optstruct5y`입니다. 1년 판(`optstruct`)과 같은 Spyder 세션에서 번갈아 돌려도 모듈이 섞이지 않습니다.
