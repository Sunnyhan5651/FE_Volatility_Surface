# KOSPI200 변동성 계속 매수 백테스트 (5년)

KOSPI200 월물 옵션으로 **스트래들 · 스트랭글 · 스트랩 · 스트립 매수**와 **콜 버터플라이 매도**를 신호 없이 항상
들고 있다가(모두 변동성 매수 방향) 만기 전에 다음 월물로 롤하는 전략 12개를, **2021-08 ~ 2026-10 (약 5년, 1,208일, 롤 63회)**
일별 데이터로 백테스트하는 리서치 저장소입니다. 날개(K/F 0.90/1.10, 25델타)와 델타헤지 여부를 조합했습니다.
1년(2025-10 ~ 2026-10)만 본 `kospi200-long-vol` 저장소와 같은 형식이고, 기간만 늘렸습니다.

> **한 줄 결론** — 5년 전체로 보면 순수한 변동성 매수(델타헤지 스트래들)는 **비용 전 +12.1%, 비용 후 +1.4%로 거의 본전**이었습니다.
> 내재변동성(평균 22.1%)과 실현변동성(23.2%)이 거의 같았기 때문입니다. 2021~2024년에는 대부분 손실, 2025~2026년에 이익으로,
> 1년 저장소의 플러스는 최근의 변동성 급등 레짐 덕이었습니다. 가장 높은 수익(스트랭글 0.90/1.10 +51%)은 **2024년 8월 급락
> 한 번**에 거의 전부 의존합니다. 12개 중 통계적으로 유의한 플러스 전략은 없습니다.

## 실행

```bash
pip install -r requirements.txt
# data/ 폴더에 KRX 원자료 CSV를 넣는다 (기간별 파일 여러 개 가능, data/README.md 참고)
python run_all.py                  # 결과표 출력 + 전략별 그래프 12장
python run_all.py --no-plot        # 결과표만
python run_all.py --by-year        # 연도별 손익 표 추가 (그래프 없음)
python run_all.py --save figures   # 그래프를 figures/ 에 PNG로도 저장
pytest -q                          # 단위 테스트 (원자료 불필요)
```

**Spyder**에서는 `run_all.py`를 열고 F5를 누르면 됩니다. 그래프는 Plots 창에 전략별로 한 장씩 나옵니다.

저장소·데이터 폴더는 자동으로 찾습니다 (저장소 `data/` → 작업 폴더 → 바탕화면/다운로드/문서와 그 하위 폴더 2단계까지, OneDrive·한글 폴더명 포함). 실행하면 결과표 맨 위에 사용한 데이터 폴더가 표시됩니다.
못 찾으면 `python run_all.py --data-dir 데이터폴더경로`. 처음 한 번은 5년치 일별 스마일을 만드느라 수 분 걸리고, 이후에는 `.cache`를 써서 30초 안쪽입니다. 데이터 파일을 추가·교체하면 캐시는 자동으로 다시 만들어집니다.

## 출력

1. **결과표 1개** — 전략 12개: 누적수익률, 비용 제외 누적수익률, Sharpe, MDD, 롤당 평균수익률, 승률, 롤 횟수, 대체평가 비율, Newey-West t
2. **그래프 12장** — 전략마다 한 장, 누적수익률 선 하나
3. (`--by-year`) **연도별 손익 표** — 연도별 시장 수익률·IV·RV와 전략별 연도 손익

### 전략 12개 (모두 변동성 매수 방향)

| 구조 | 날개 | 델타헤지 없음 | 델타헤지 |
|---|---|---|---|
| 스트래들 (풋 + 콜, K=F) | — | ✓ | ✓ |
| 스트랭글 (풋 날개 + 콜 날개) | 0.90 / 1.10 | ✓ | ✓ |
| 스트랭글 | 25Δ | ✓ | ✓ |
| 스트랩 (풋 1 + 콜 2, K=F) | — | ✓ | |
| 스트립 (풋 2 + 콜 1, K=F) | — | ✓ | |
| 콜 버터플라이 **매도** (콜 K1 매도 / 콜 F 2개 매수 / 콜 K3 매도) | 0.90 / 1.10 | ✓ | ✓ |
| 콜 버터플라이 매도 | 25Δ | ✓ | ✓ |

* **25Δ 날개**는 진입일 스마일의 IV로 계산한 |델타| = 0.25인 풋·콜 행사가입니다.
* **나비 매도 = 변동성 매수.** 롱 버터플라이는 가격이 제자리에 있어야 버는 변동성 매도이고, 그 반대인 나비 매도는 크게 움직여야 버는 변동성 매수입니다. 날개를 팔았기 때문에 날개 밖에서는 이익이 막힙니다. 25Δ처럼 행사가 간격이 다르면 날개 수량을 `2(K3−K2)/(K3−K1)`, `2(K2−K1)/(K3−K1)`로 맞춰 양쪽 꼬리의 만기 손익을 0으로 만듭니다.
* **스트랩·스트립은 델타헤지 버전을 넣지 않았습니다.** 베가를 맞추면 스트랩 = 스트래들 + 선물 매수 1/3, 스트립 = 스트래들 + 선물 매도 1/3이라, 델타헤지하면 둘 다 스트래들과 똑같아집니다.

## 방법 요약

**데이터.** 기간별로 나뉜 KRX 파일(`kospi200_YYYYMMDD_YYYYMMDD_options_regular.csv.gz` 등)을 폴더에서 모두 찾아 날짜순으로 합칩니다. 포지션은 파일 경계와 무관하게 이어집니다.

**IV 스마일.** 날짜·만기별로 거래량 ≥10, 미결제약정 ≥10, IV 3~150%, 잔존 5~180일, K/F 0.85~1.15 필터를 통과한 OTM 옵션의 IV를 거래량 가중해 스마일을 만들고, 행사가 방향으로 선형 보간합니다(진입 시 외삽 없음). F는 같은 만기 선물 종가입니다.

**롤 규칙.** 신호·손절·보유일 제한 없이 항상 변동성 매수 포지션을 듭니다. 잔존 5일 미만이 된 날 종가에 팔고, 다음 날 잔존 10일 이상인 가장 가까운 월물을 삽니다 (보통 잔존 약 30일에 사서 약 4일에 팔아 월 1회 롤).

**크기.** 구조 전체 베가 = 진입일 ATM 스트래들 1개의 베가. 콜 버터플라이만 몸통 = ATM 콜 2개(≈ 스트래들 1개 베가)로 둡니다.

**회계.** 손익 = (옵션 평가액 − 진입가) + 누적 헤지손익. 옵션 비용은 진입·청산 각각 레그당 0.5 IV-pt (매수는 비싸게, 매도는 싸게).
델타헤지는 매일 종가에 선물로 재헤지하고, 진입 헤지·재헤지·헤지 해제 때 거래한 선물 1단위당 0.05pt(1틱)의 비용을 뺍니다. 수익률은 롤별 진입 선물가 기준 %, 가산 누적.

**MDD.** 자본 1(진입 선물가 명목 1단위)에서 시작해 누적손익을 단순 합산한 잔고를 기준으로, 직전 최고 잔고 대비 최대 하락률(%)입니다.

**보유 중 평가.** 급변으로 행사가가 그날 스마일 범위 밖으로 나가면 날개 IV를 평평하게 외삽하고, 만기 스마일이 통째로 없으면 직전 IV를 유지해 **그날 손익을 반영**합니다(건너뛰거나 전날로 청산하지 않음). 결과표의 `대체평가 %`가 이렇게 평가한 보유일의 비율입니다.

- **5년 전체로는 변동성 매수 ≈ 본전입니다.** IV(22.1%)와 RV(23.2%)가 거의 같아, 델타헤지 스트래들은 비용 전 +12.1%가 비용(약 10.7%p) 후 +1.4%가 됐습니다. 63번 롤하는 동안 비용이 엣지를 거의 다 가져갑니다.
- **해마다 결과가 크게 다릅니다.** 2021~2024년은 대부분 손실이고, 2025~2026년 변동성 레짐이 급등하면서(2026년 IV 평균 52%) 이익이 났습니다. 1년만 본 `kospi200-long-vol`의 플러스는 이 마지막 구간의 결과였습니다.
- **스트랭글 0.90/1.10의 +51%는 사실상 한 번의 사건입니다.** 2024-07-09에 진입한 롤 하나가 +53.4%를 냈는데, 그중 +51.3%가 KOSPI200이 급락한 2024-08-05 하루에 나왔습니다(마침 그날이 롤 청산일이기도 했습니다). 상위 5개 롤 합이 +129.8%, 나머지 58개 롤은 합계 −78.7%입니다(승률 14%). IV가 낮은 해에는 10% OTM 날개의 베가가 작아서, 베가를 ATM 스트래들에 맞추느라 수량이 평균 9~14배로 커집니다. 즉 이 전략은 **레버리지된 꼬리 베팅**이고, 그런 급락이 없는 기간이라면 큰 손실입니다.
- **스트랩·스트립의 차이는 여전히 시장 방향입니다.** KOSPI200 +110% 구간에서 스트랩 +22.2%, 스트립 −28.3%. 하락한 2022년에는 반대로 스트립이 +11.9%로 가장 좋았습니다.
- **나비 매도는 비용 전에도 이익이 작습니다.** 날개가 큰 움직임의 이익을 되돌려 주기 때문입니다. 25Δ 무헤지(NW t −2.19)는 비용 전에도 −13.7%로, 12개 중 유일하게 통계적으로 유의한 결과가 "손실"이었습니다.
- **델타헤지는 손실 폭을 줄입니다.** 스트래들 MDD −37.6% → −12.0%, 스트랭글 25Δ −24.5% → −9.8%.

## 한계와 주의

* **표본:** 5년이지만 한국 시장 하나, 레짐이 크게 바뀐 기간입니다. 롤 63회 중 몇 번의 사건이 결과를 좌우합니다.
* **수량 레버리지:** 구조끼리 베가를 맞추는 방식이라, IV가 낮을 때 먼 OTM 날개를 쓰는 전략(0.90/1.10)은 계약 수가 크게 늘어납니다. 프리미엄이나 증거금 기준으로 맞추면 결과가 달라집니다.
* **날개 평가:** 0.90/1.10 날개는 보유일의 34%, 25Δ는 15%를 외삽 IV로 평가했습니다. 실제 날개 IV는 보통 더 높아 수치가 다소 틀릴 수 있습니다.
* **표본 날짜:** 만기가 2개 이상 거래된 날만 씁니다(1,208일). 2026년은 거래일 197일 중 154일입니다.
* **일별 데이터:** 체결가는 종가, 델타헤지는 하루 한 번 종가에만 합니다. 옵션 비용(0.5 IV-pt)과 선물 비용(1틱)은 가정치이며 `config.py`에서 바꿀 수 있습니다.
* **단순화:** 무위험금리 연 2.5% 고정, 증거금·포지션 한도 미모델링. 이 저장소는 학습·리서치 목적이며 투자 권유가 아닙니다.
