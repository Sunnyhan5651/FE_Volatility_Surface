# data/

KRX 원자료 CSV를 이 폴더에 넣습니다 (저장소에는 올리지 않음, `.gitignore`).
기간별로 나뉜 파일을 여러 개 넣어도 되고, `run_all.py`가 모두 찾아 날짜순으로 합칩니다.

| 종류 | 파일 이름 예시 | 내용 |
|---|---|---|
| 옵션 | `kospi200_20210826_20220902_options_regular.csv.gz`, `kospi200_options_regular.csv.gz` | 코스피200 옵션 일별 정규세션 (행사가, 종가, 내재변동성, 거래량, 미결제약정, 최종거래일) |
| 선물 | `kospi200_20210826_20220902_futures_regular.csv.gz`, `kospi200_futures_regular.csv` | 코스피200·미니코스피200 선물 일별 (만기별 종가, 거래량) |
| 지수 | `kospi200_20210826_20220902_spot.csv.gz`, `kospi200_spot.csv` | 코스피200 지수 일별 종가 |

이름 규칙: `kospi200`로 시작하고 `options_regular.csv` / `futures_regular.csv` / `spot.csv`로 끝나면 됩니다 (`.gz` 압축 그대로 가능).
결과표의 5년 수치는 2021-08-26 ~ 2026-10-23 파일 5묶음(옵션·선물·지수 각 5개)으로 만든 것입니다.

이 폴더가 아니라 바탕화면·다운로드·문서 아래 다른 폴더(예: `바탕화면/변동성 표면/시계열`)에 있어도 `run_all.py`가 자동으로 찾습니다.
