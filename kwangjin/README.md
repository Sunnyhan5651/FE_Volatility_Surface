# KOSPI200 변동성 곡면 차익거래 리서치

## kospi200-vol-arb-5y: 스큐(0.90/1.10 IV 차이), 캘린더(원월−근월 IV), VRP(IV−RV)랑 스큐 변형 다룸

## kospi200-option-structures-5y: VRP 신호에 따라 IV가 비싸면 변동성을 팔고 싸면 사는 방식으로 스트래들·스트랭글·스트랩·스트립·콜 버터플라이 다룸

## kospi200-long-vol-5y: 신호 없이 같은 12개 구조를 항상 변동성 매수 쪽으로 들고 있다가 만기 직전에 다음 월물로 롤링시키도록 함

KOSPI200 월물 옵션의 내재변동성(IV) 곡면에서 **스큐 · 캘린더(기간구조) · IV–RV(VRP)** 세 가지 차익거래 전략과
스큐 변형 12가지를 일별 데이터로 백테스트하고 통계검증한 리서치(학기 프로젝트) 저장소입니다.

> **한 줄 결론** — 이 표본(2025-10 ~ 2026-10, 상승 후 조정의 단일 사이클, 204일)에서 비용을 반영한 **거래 가능한 알파는 확인되지 않았습니다.**
> 스큐의 수익은 신호가 나온 *당일 종가*에 체결한다고 가정할 때만 나타나고, 다음날 체결로 바꾸면 사라졌습니다.

## 실행

```bash
pip install -r requirements.txt
# data/ 폴더에 KRX 원자료 CSV 3개를 넣는다 (data/README.md 참고)
python run_all.py              # 결과표 + 통계검정 출력, 전략별 그래프 15개를 화면에 표시
python run_all.py --no-plot    # 표만
python run_all.py --quick      # 순열검정 횟수를 줄여 빠르게
pytest -q                      # 단위 테스트 (원자료 불필요)
```

저장소·데이터 폴더는 자동으로 찾습니다 (스크립트 위치 → 작업 폴더 → 바탕화면/다운로드/문서, OneDrive·한글 폴더명 포함).
못 찾으면 `python run_all.py --data-dir 데이터폴더경로`. 최초 1회는 일별 스마일을 만드느라 몇 분 걸리고, 이후에는 `.cache`를 써서 30초 안쪽입니다.

## 출력

파일은 저장하지 않고 콘솔과 화면에만 보여줍니다.

1. **결과표 1개** — 전략 15개 × 체결 가정 2개(당일/익일 종가 체결): 누적수익률, Sharpe, **MDD**, 최악 셀 MDD, 거래당 평균수익률, 승률, 거래수, Newey-West t
2. **통계검정** — 스큐 평균회귀 검정(HAC·순열·비중첩 p값)과, 진입을 1~2일 미루거나 잔존일을 통제했을 때의 견고성
3. **그래프 15개** — 전략마다 한 장, 누적수익률 선 2개(당일 체결 / 익일 체결)만 그린 단순한 시계열

### 전략 15개

| 구분 | 이름 | 내용 |
|---|---|---|
| 기본 | 스큐 (기본) | 신호 `IV(K/F=0.90) − IV(1.10)`, 리스크리버설 (풋 0.90 / 콜 1.10) |
| 기본 | 캘린더 | 원월 ATM IV − 근월 ATM IV, 베가 중립 스트래들 스프레드 |
| 기본 | VRP | 근월 ATM IV − 20일 실현변동성, ATM 스트래들 (잔존일 사이징) |
| 스큐 변형 | + S | 신호 z가 진입 때보다 1.0 더 벌어지면 손절 |
| | + D | 잔존 10일 미만이면 진입 금지 |
| | + M | z-score를 평균·표준편차 대신 중앙값·MAD로 계산 |
| | + S + D, S + M, D + M, S + D + M | 위 변형의 조합 |
| | SMA3 | 스큐 신호를 3일 평균으로 평활 (거래 행사가는 기본과 동일) |
| | D25 | 신호를 25델타 `IV(풋) − IV(콜)`로 재정의 (거래 행사가는 기본과 동일) |
| | D25L | D25 신호 + 거래 행사가도 25델타 풋/콜 |
| | D25S, D25SL | D25 신호를 3일 평활 (SL은 행사가도 25델타) |

## 방법 요약

**IV 곡면.** 날짜·만기별로 거래량 ≥10, 미결제약정 ≥10, IV 3~150%, 잔존 5~180일, K/F 0.85~1.15 필터를 통과한 OTM 옵션의 IV를
거래량 가중해 스마일을 만들고 행사가 방향으로 선형 보간합니다(외삽 없음). 선물가 F는 같은 만기 선물 종가입니다.

**신호.** 지표의 rolling z-score (윈도우 W∈{20,40,60}), 진입 |z|≥E∈{1.0,1.5,2.0}, 청산 |z|<0.3, 최대 보유 5일.
결과표의 각 전략은 이 9개 셀의 일별 손익을 평균한 곡선입니다 (사후에 좋은 셀을 고르지 않기 위함).

**회계.** 손익 = (옵션 평가액 − 진입가) + 누적 헤지손익. 비용은 진입·청산 각각 레그당 0.5 IV-pt (매수는 비싸게, 매도는 싸게).
일별 델타 재헤지, 한 번에 하나의 포지션, 수익률은 진입 선물가 기준 가산 누적.

**체결 가정.** 당일 체결 = 신호가 나온 날 종가에 체결(낙관적 상한), 익일 체결 = 다음날 종가에 체결(보수적 하한). 현실은 그 사이입니다.

## 주요 결과 (결과표에서 발췌)

| 전략 | 체결 | 누적수익률 % | Sharpe | MDD %p | NW t |
|---|---|---|---|---|---|
| 스큐 (기본) | 당일 | +2.07 | 1.99 | −0.29 | 1.72 |
| 스큐 (기본) | 익일 | −0.85 | −0.91 | −1.36 | −0.91 |
| 캘린더 | 당일 / 익일 | −2.02 / −0.53 | −0.65 / −1.32 | −3.99 / −0.66 | −0.82 / −1.10 |
| VRP | 당일 / 익일 | −8.36 / −8.53 | −1.68 / −1.85 | −8.79 / −8.70 | −1.68 / −1.74 |
| 스큐 D25S | 당일 / 익일 | +0.38 / +0.21 | 0.71 / 0.53 | −0.35 / −0.36 | 0.82 / 0.62 |

- 스큐의 수익은 체결 가정에 크게 의존합니다 (당일 +2.07% → 익일 −0.85%). 평활(SMA3, D25S)과 25델타 신호는 이 의존성을 줄였지만 비용 후 수익은 유의하지 않습니다 (D25S 익일 t=0.62).
- 손절(S)은 포지션이 평균 며칠 만에 청산되어 거래 결과가 달라지지 않았고, 잔존일 필터(D)는 오히려 성과를 낮췄습니다.
- 캘린더는 원월 ATM 호가가 있는 날이 79일뿐이라 거래가 거의 없어 **검증 불가**입니다.
- 통계검정: 사전지정 사양(W=40, h=10, 같은 만기 쌍) b = −2.00, NW t = −2.78 (p=0.004, 순열 p=0.020)로 평균회귀 자체는 존재합니다. 그러나 진입을 하루 미루면 계수가 약 1/3로, 이틀 미루면 사라지고, 일별 스큐 변화의 1차 자기상관이 −0.28이어서 하루짜리 되돌림(종가 IV의 일시적 오차로 추정)이 큽니다.

## 한계와 주의

* **표본:** 204일, 상승 후 조정의 단일 사이클. 셀당 유효 거래가 0~20건이라 개별 수치는 근거가 되지 못합니다.
* **다중비교:** 전략 15개 × 체결 2종 × 격자를 비교했으므로 좋아 보이는 결과(예: D25S)에는 사후 선택에 따른 낙관 편향이 있습니다.
* **일별 데이터:** 호가·장중 데이터가 없어 체결가를 종가로 가정하고, 비용(0.5 IV-pt)도 가정치입니다.
* **단순화:** 무위험금리 연 2.5% 고정, 증거금·포지션 한도 미모델링. 이 저장소는 학습·리서치 목적이며 투자 권유가 아닙니다.
