# data/

KRX 원자료 CSV 3개를 이 폴더에 넣습니다 (저장소에는 올리지 않음, `.gitignore`).

| 파일 | 내용 |
|---|---|
| `kospi200_options_regular.csv` 또는 `.csv.gz` | 코스피200 옵션 일별 정규세션 (행사가, 종가, 내재변동성, 거래량, 미결제약정, 최종거래일) |
| `kospi200_futures_regular.csv` | 코스피200·미니코스피200 선물 일별 (만기별 종가, 거래량) |
| `kospi200_spot.csv` | 코스피200 지수 일별 종가 |

옵션 파일은 압축(`.csv.gz`)된 채로 두어도 됩니다. 이 폴더가 아니라 바탕화면·다운로드·문서 아래 다른 폴더(예: `바탕화면/변동성 표면`)에 있어도 `run_all.py`가 자동으로 찾습니다.
