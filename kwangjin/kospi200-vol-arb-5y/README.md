# KOSPI200 변동성 곡면 차익거래 리서치 (5년 판)

KOSPI200 월물 옵션의 내재변동성(IV) 곡면에서 **스큐 · 캘린더(기간구조) · IV–RV(VRP)** 세 가지 차익거래 전략과
스큐 변형 12가지를 일별 데이터로 백테스트하고 통계검증한 리서치(학기 프로젝트) 저장소입니다.

[kospi200-vol-arb](../kospi200-vol-arb)(1년, 2025-10 ~ 2026-10)와 같은 전략·같은 출력 형식이고, 기간만 **2021-08-26 ~ 2026-10-23 (1,208 거래일)** 로 늘렸습니다.
보유 중 평가 방식을 고치고 선물 헤지 비용을 더했기 때문에 1년 구간 숫자도 원래 저장소와 조금 다릅니다 (아래 [이력](#이력-1년-판과-다른-점)).

> **한 줄 결론** — 5년으로 늘리자 스큐의 **평균회귀 자체는 훨씬 강하게 확인**됐습니다 (사전지정 사양 NW t = −8.3, 1년 판 −2.8).
> 그런데도 비용을 반영한 **거래 가능한 알파는 여전히 없습니다.** 가장 나은 스큐 (기본)·당일 체결이 5년 누적 +3.2% (t 1.15)인데,
> 그중 +1.6%가 2024-08-05 하루에서 나왔고, 같은 전략을 다음날 체결로 바꾸면 −3.0%입니다. VRP(변동성 매도/매수)는 −44 ~ −46%로 확실한 손실입니다.

## 실행

```bash
pip install -r requirements.txt
# data/ 폴더에 기간별 KRX 원자료 CSV 15개를 넣는다 (data/README.md 참고)
python run_all.py                    # 결과표 + 통계검정 출력, 전략별 그래프 15장 표시
python run_all.py --no-plot          # 표만
python run_all.py --by-year          # 연도별 손익 표 추가
python run_all.py --save figures     # 그래프를 figures/ 에 PNG 로도 저장
python run_all.py --quick            # 순열검정 횟수를 줄여 빠르게
pytest -q                            # 단위 테스트 (원자료 불필요)
```

Spyder에서는 `run_all.py`를 열고 F5. 저장소·데이터 폴더는 자동으로 찾습니다
(스크립트 위치 → 작업 폴더 → 바탕화면/다운로드/문서와 그 하위 폴더 2단계, OneDrive·한글 폴더명 포함). 찾은 데이터 폴더는 결과표 머리말에 찍힙니다.
못 찾으면 `python run_all.py --data-dir 데이터폴더경로`. 최초 1회는 5년치 일별 스마일을 만드느라 몇 분 걸리고, 이후에는 `.cache`를 씁니다.
전체 실행(순열검정 2,000회 포함)은 2~3분, `--quick`은 그보다 빠릅니다.

## 출력

1. **결과표 1개** — 전략 15개 × 체결 가정 2개(당일/익일 종가 체결): 누적수익률, Sharpe, **MDD(%)**, 최악 셀 MDD, 거래당 평균수익률, 승률, 거래수, Newey-West t
2. **(선택) 연도별 손익표** — `--by-year`
3. **통계검정** — 스큐 평균회귀 검정(HAC·순열·비중첩 p값)과, 진입을 1~2일 미루거나 잔존일을 통제했을 때의 견고성
4. **그래프 15장** — 전략마다 한 장, 누적수익률 선 2개(당일 체결 / 익일 체결)

### 전략 15개

| 구분 | 이름 | 내용 |
|---|---|---|
| 기본 | 스큐 (기본) | 신호 `IV(K/F=0.90) − IV(1.10)`, 리스크리버설 (풋 0.90 / 콜 1.10) |
| 기본 | 캘린더 | 원월 ATM IV − 근월 ATM IV, 베가 중립 스트래들 스프레드 |

| | + M | z-score를 평균·표준편차 대신 중앙값·MAD로 계산 |

## 방법 요약

**데이터.** `data/` 폴더의 `kospi200*_options_regular`, `*_futures_regular`, `*_spot` 파일(.csv / .csv.gz)을 **기간별로 전부** 읽어 날짜순으로 이어 붙입니다.

**IV 곡면.** 날짜·만기별로 거래량 ≥10, 미결제약정 ≥10, IV 3~150%, 잔존 5~180일, K/F 0.85~1.15 필터를 통과한 OTM 옵션의 IV를
거래량 가중해 스마일을 만들고 행사가 방향으로 선형 보간합니다(진입 시 외삽 없음). 선물가 F는 같은 만기 선물 종가입니다.

**신호.** 지표의 rolling z-score (윈도우 W∈{20,40,60}), 진입 |z|≥E∈{1.0,1.5,2.0}, 청산 |z|<0.3, 최대 보유 5일.
결과표의 각 전략은 이 9개 셀의 일별 손익을 평균한 곡선입니다 (사후에 좋은 셀을 고르지 않기 위함).

**회계.** 손익 = (옵션 평가액 − 진입가) + 누적 헤지손익 − 선물 거래비용.
옵션 비용은 진입·청산 각각 레그당 0.5 IV-pt (매수는 비싸게, 매도는 싸게). 일별 델타 재헤지,
**헤지 선물 비용 1단위당 0.05pt(선물 1틱)** — 진입 헤지·매일 재헤지·청산 때 헤지 해제에서 거래한 수량만큼.
한 번에 하나의 포지션, 수익률은 진입 선물가 기준 가산 누적.

**보유 중 평가.** 행사가가 그날 스마일 밖으로 나가면 날개 IV 플랫 외삽, 그 만기 스마일이 통째로 없으면 직전 IV 유지 + 선물 시세로 평가합니다.
레그 잔존일이 5일 미만이 되는 날은 그날 종가에 청산합니다.

**MDD.** 자본 1(진입 선물가 명목 1단위)에서 시작한 잔고 `1 + 누적손익`의 고점 대비 최대 낙폭 %.

**체결 가정.** 당일 체결 = 신호가 나온 날 종가에 체결(낙관적 상한), 익일 체결 = 다음날 종가에 체결(보수적 하한). 현실은 그 사이입니다.

**읽는 법**

- **평균회귀는 진짜다.** 사전지정 사양(W=40, h=10, 같은 만기 쌍) b = −1.35, NW t = −8.32, 순열 p < 0.001. 9개 사양 모두 t ≤ −6.6이고,
  진입을 하루(t −7.9)·이틀(t −4.5) 미루거나 잔존일을 통제해도 남습니다. 1년 판(t −2.8, 이틀 미루면 사라짐)보다 훨씬 견고합니다.
- **그런데 돈이 안 된다.** 스큐 계열은 비용을 빼면 대부분 +이지만(스큐 기본 당일 +6.6%, 익일 +0.2%), 비용 0.5 IV-pt × 2레그 × 진입·청산을 내면 0 근처로 떨어집니다.
  b = −1.35는 z가 1.5일 때 10일 뒤 스큐가 약 2 IV-pt 되돌아온다는 뜻인데, 리스크리버설 왕복 비용이 이와 같은 크기입니다. 게다가 보유는 최대 5일입니다.
- **하루짜리 잡음이 크다.** 일별 스큐 변화의 1차 자기상관이 −0.30입니다. 측정된 되돌림의 상당 부분은 종가 IV의 일시적 오차로 보이고, 이 부분은 거래로 잡을 수 없습니다.
- **당일 vs 익일 차이는 하루가 만든다.** 스큐 (기본)의 두 체결 가정 차이 6.3%p 중 4.5%p가 2024-08-05(엔 캐리 청산 폭락일) 하루에서 나왔습니다 (당일 +1.6%, 익일 −2.9%).
  이 날과 상·하위 5일을 빼면 당일 체결도 +0.4%뿐입니다.
- **VRP는 확실히 진다.** 매년 손실이고 t ≈ −5. 비용을 빼도 −15 ~ −19%. 5년 평균으로 RV가 IV보다 높았고(23.2 vs 22.1), 특히 2024·2026년 RV가 IV를 크게 웃돌아
  "IV가 비싸면 판다" 신호가 큰 실현변동성에 계속 맞았습니다.
- **캘린더는 여전히 거래가 적다** (셀당 5~13건, 원월 ATM 호가가 있는 날이 적음). 숫자는 참고용입니다.
- 0.90/1.10 행사가로 거래하는 스큐 계열은 보유일의 11~20%를 날개 행사가가 스마일 밖이라 외삽·직전 IV로 평가했습니다 (25델타 행사가 L 계열은 8~10%). 저변동성 구간에는 0.90/1.10 날개 거래가 얇기 때문입니다.

## 한계와 주의

* **다중비교:** 전략 15개 × 체결 2종 × 격자를 비교했으므로 좋아 보이는 결과(예: SMA3 익일 +1.1%)에는 사후 선택에 따른 낙관 편향이 있습니다. 어떤 스큐 변형도 NW t ≥ 2가 아닙니다.
* **집중도:** 몇 안 되는 급변일(2024-08-05, 2026-07)이 누적 결과의 대부분을 정합니다.
* **일별 데이터:** 호가·장중 데이터가 없어 체결가를 종가로 가정하고, 비용(옵션 0.5 IV-pt, 선물 0.05pt)도 가정치입니다.
* **단순화:** 무위험금리 연 2.5% 고정, 증거금·포지션 한도 미모델링. 이 저장소는 학습·리서치 목적이며 투자 권유가 아닙니다.

## 이력 (1년 판과 다른 점)

1. **기간별 파일 여러 개 읽기** — 옵션·선물·현물 파일을 기간별로 모두 읽어 이어 붙입니다. 원래 1년 파일 3개만 넣으면 원래 저장소와 같은 스마일·신호가 나옵니다
   (통계검정 b = −2.00, NW t = −2.78 그대로 재현).
2. **보유 중 평가 수정** — 원래 엔진은 보유 중 행사가 보간이 안 되거나 만기가 스마일 필터(잔존 5일)를 벗어나면 **전날 값으로 소급 청산**했습니다.
   이 규칙은 그날의 실제 손익을 건너뛰어 결과를 왜곡합니다. 5년 판은 외삽·직전 IV로 평가를 계속하고, 잔존 5일 미만이 되는 날 종가에 청산합니다.
3. **선물 헤지 비용 추가** — 델타 헤지 선물 거래 1단위당 0.05pt.
4. **MDD를 %로** — 누적손익 차이(%p) 대신 잔고 1 + 누적손익의 고점 대비 낙폭 %.

같은 1년 구간(2025-10 ~ 2026-10)에서의 차이 (누적수익률 %):

| 전략 | 원래 엔진 당일 / 익일 | 5년 판 엔진 당일 / 익일 |
|---|---|---|
| 스큐 (기본) | +2.07 / −0.85 | +2.40 / +2.11 |
| VRP | −8.36 / −8.53 | −8.43 / −9.26 |
| 캘린더 | −2.02 / −0.53 | −3.83 / −0.98 |
| 스큐 D25S | +0.38 / +0.21 | −1.22 / −0.49 |

5년 전체에서도 원래 엔진(1, 2~4 미적용)으로 돌리면 스큐 (기본) +1.09 / −2.83, VRP −39.80 / −43.46으로 결론은 같습니다.
